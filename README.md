## ✨ Funcionalidades

O projeto atende aos seguintes requisitos:
- **Adicionar novos itens:** Inserção de itens na lista através de um campo de texto.
- **Validação simples:** Impede a adição de itens vazios.
- **Marcar como concluído:** Checkbox interativo que altera o estado visual do item (texto riscado e opacidade reduzida).
- **Remover itens:** Exclusão individual de itens da lista com feedback visual.
- **Alertas dinâmicos:** Exibição de uma mensagem temporária na parte inferior da tela ao remover um item.
- **Design Responsivo:** Layout adaptável para dispositivos móveis (Mobile First) e desktops, utilizando Media Queries.

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído utilizando as tecnologias base da web:

- **HTML5:** Estruturação semântica da página.
- **CSS3:** - Estilização baseada em um protótipo do Figma.
  - Uso de **Variáveis CSS** (`:root`) para padronização de cores e tipografia.
  - Layout flexível com **Flexbox**.
  - Abordagem **Mobile First** e responsividade com `@media queries`.
- **JavaScript (ES6+):** - Manipulação do DOM (`getElementById`, `createElement`, `appendChild`).
  - Escuta de eventos (`addEventListener`).
  - Delegação de eventos (Event Delegation) para gerenciar cliques dinâmicos na lista.
  - Temporizadores (`setTimeout`) para controle de exibição do alerta.
